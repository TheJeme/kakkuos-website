KakkuOS

A layered Linux desktop that keeps CachyOS as the fast hardware foundation, then adds a complete KakkuOS experience.

Install KakkuOS View source

Install

Install CachyOS first, then run the KakkuOS installer.

Run on CachyOS 
curl -fsSL https://kakkuos.jeme.app/install | sh

Stack

Base

CachyOS provides the kernel, repositories, hardware enablement, gaming stack, and low-level performance tuning.

Wayland

Scrollable tiling Wayland defaults with xwayland-satellite, portal configuration, screenshot behavior, and Kakku keybinds.

Shell

DMS provides the bar, launcher, notifications, control center, wallpaper browser, and greeter path.

CLI

Ghostty, fish, Starship, fastfetch, Yazi, btop, tmux, ripgrep, fd, jq, HTTPie, Glow.

Apps

Zen Browser, Dolphin, Vesktop, Cider, and Zathura.

Services

NetworkManager, Bluetooth, Docker, Tailscale, UFW, ananicy-cpp.

Media

PipeWire, WirePlumber, mpv, imv, Loupe, OBS Studio, Kdenlive, SpeedCrunch, and LibreOffice.

Theme

Wallpapers, logo assets, theme files, and shell defaults.
