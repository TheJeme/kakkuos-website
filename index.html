What it is

A complete OS experience built on CachyOS.

KakkuOS uses CachyOS as its performance-focused foundation and builds a distinct Hyprland system on top: curated software, desktop defaults, dotfiles, themes, branding, helper commands, and installer flow. The goal is a real daily-driver OS while still benefiting from CachyOS hardware support, repositories, kernel work, and low-level tuning.

Stack

Built from proven Linux desktop parts.

Hy

Hyprland session

Wayland compositor defaults for wallpaper, idle handling, lock screen, portals, color picking, and display comfort.

UI

Useful desktop tools

Waybar, Rofi, Kitty, Dolphin, Firefox, Mako, fonts, screenshots, brightness, audio, and notifications.

PK

Curated system

Package sets for core services, desktop apps, CLI tools, development, gaming, media, repo extras, and AUR software.

KT

Kakku tooling

A small command suite for diagnostics, paths, package information, version details, and theme management.

Install

Install KakkuOS on a CachyOS base.

Start with CachyOS Hyprland and run the hosted installer. It clones the Kakku repository, runs the project installer, installs packages with --needed, copies dotfiles, backs up changed local configs, and enables common services when available. 

curl -fsSL https://kakkuos.jeme.app/install.sh | bash

Commands

Small helpers for everyday maintenance.

kakku infoShow base OS, kernel, Hyprland, and theme information.
kakku doctorCheck expected commands, configs, theme paths, wallpaper, and services.
kakku packagesReview installed package set information.
kakku theme set <theme>Apply a Kakku theme across the configured desktop.
