What it is

A complete OS experience with its own flavor.

KakkuOS uses CachyOS as its performance-focused foundation and builds a distinct niri and DankMaterialShell system on top: curated software, desktop defaults, dotfiles, branding, helper commands, and installer flow. The goal is a real daily-driver OS while still benefiting from CachyOS hardware support, repositories, kernel work, and low-level tuning.

Stack

Built from proven Linux desktop parts.

Ni

niri session

Scrollable tiling Wayland defaults with xwayland-satellite, screen sharing portals, screenshots, and greetd launching niri-session.

DM

DankMaterialShell

DMS provides the bar, launcher, notifications, control center, lock/session UI, wallpaper controls, and Material color integration.

PK

Curated system

Package sets for core services, desktop apps, CLI tools, development, gaming, media, repo extras, and AUR software.

KT

Kakku tooling

A small command suite for diagnostics, services, keybinds, paths, package information, defaults, DMS plugins, and updates.

Defaults

A coherent niri workspace from first login.

01

niri + DMS

Scrollable tiling with a complete shell layer for launchers, status, notifications, lock, and settings.

02

Ghostty

A GPU-accelerated terminal paired with Kakku shell defaults and developer-friendly fonts.

03

fish + Starship

fish is the default login shell, with zsh and bash defaults still available.

04

Zen Browser

Zen handles web links by default, with Firefox kept as a fallback and browser policies applied.

05

Dolphin + yazi

Graphical and terminal file managers are both part of the default desktop workflow.

06

DMS plugins

The installer sets up the AI Assistant and Calculator plugins under DankMaterialShell.

07

matugen colors

Wallpaper-based Material colors keep the shell, prompts, and branding visually aligned.

08

Core services

NetworkManager, Bluetooth, Docker, Tailscale, and power profiles are enabled when available.

Install

Install KakkuOS.

Start with CachyOS, choose niri if the installer offers it, then run the hosted installer. It clones the Kakku repository, runs the project installer, installs packages with --needed, copies dotfiles, backs up changed local configs, configures greetd for niri-session, and enables common services when available.

Commands

Small helpers for everyday maintenance.

kakku infoShow Kakku, base OS, kernel, niri, and DankMaterialShell information.
kakku doctorCheck expected commands, configs, branding assets, defaults, DMS plugins, and key services.
kakku doctor --fixReapply safe local defaults, refresh DMS plugins, apply browser policies, set fish, and enable core services.
kakku keybindsPrint the default keyboard shortcuts.
kakku packagesReview installed package set information.
kakku dms-pluginsInstall or update the default DankMaterialShell AI Assistant and Calculator plugins.
