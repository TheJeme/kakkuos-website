KakkuOS

A layered Linux operating system that keeps CachyOS as the optimized base and adds a complete KakkuOS desktop.

Install KakkuOS View source

Install

Install CachyOS first, then run KakkuOS installer.

Terminal 
curl -fsSL https://kakkuos.jeme.app/install | sh

Stack

Base

CachyOS provides the optimized kernel, repositories, driver support, and performance tuning out of the box.

Wayland

Scrollable tiling Wayland defaults with xwayland-satellite and desktop portal integration.

Shell

DankMaterialShell provides the bar, launcher, notifications, control center, and greeter.

CLI

Ghostty, fish, Starship, Zoxide, eza, Yazi, btop, tmux, ripgrep, fd, jq, HTTPie, and Glow.

Desktop

Zen Browser, Dolphin, VS Code, Pinta, Steam, Vesktop, Cider, and Zathura.

Services

NetworkManager, BlueZ, UFW, Docker, Tailscale, and ananicy-cpp.

Media

PipeWire, WirePlumber, mpv, imv, Loupe, OBS Studio, Kdenlive, SpeedCrunch, and LibreOffice.

Theme

Wallpapers, theme files, and shell defaults.

Commands
