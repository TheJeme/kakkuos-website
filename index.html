KakkuOS

A layered Linux operating system that keeps CachyOS as the optimized base and adds a complete KakkuOS desktop.

Install KakkuOS View source

Install

Install CachyOS first, then run KakkuOS installer.

Terminal 
curl -fsSL https://kakkuos.jeme.app/install | sh

Stack

Base

CachyOS provides the kernel, repositories, driver support, and performance tuning out of the box.

Wayland

Scrollable tiling Wayland defaults with xwayland-satellite and desktop portal integration.

Shell

DankMaterialShell provides the bar, launcher, notifications, control center, and greeter.

CLI

Ghostty, fish, Starship, Zoxide, eza, Yazi, btop, calccu, ripgrep, fd, fzf, jq, HTTPie, and Glow.

Desktop

Zen Browser, Dolphin, VS Code, Pinta, Steam, Vesktop, Sidra, and Zathura.

Services

NetworkManager, BlueZ, UFW, Docker, Tailscale, greetd, and ananicy-cpp.

Media

PipeWire, WirePlumber, mpv, imv, Loupe, OBS Studio, Kdenlive, and ONLYOFFICE.

Theme

Wallpapers, GTK and icon themes, cursor style, font configuration, color scheme, and shell defaults.
